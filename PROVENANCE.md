# Provenance

## Summary

Every file in this repository is original work written for WHIRL, apart from the third-party
material marked "adapted from" below and listed in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
The design follows NInfer's philosophy (Apache-2.0, ideas only). The C++ code was written as a clean
reimplementation of WHIRL's own Zig research prototype; behaviour was verified black-box (bit-exact
outputs) against that prototype. An identifier-level overlap scan against the public zynfer repository
found no shared code (one match: the public Qwen chat-template string).

## Origin labels

- **new**: written from scratch for WHIRL.
- **reimplemented from the prototype (`<file>`)**: written in C++ for WHIRL, following the logic of the
  named file of WHIRL's own Zig research prototype (code written by this project). The prototype is not
  part of this repository.
- **carried over from the prototype's kernel source**: HIP device code that this project wrote for the
  prototype, moved into this repository (see the kernel table).
- **adapted from `<project>` under `<license>`**: third-party code, also listed in THIRD_PARTY_NOTICES.md.

"Verified" in the notes means the check was run against the prototype executable as a black box
(same inputs, outputs compared token for token or bit for bit).
